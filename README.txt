# CampusPilot AI — Free Prototype

This is a browser-based prototype of the College Daily Assistant concept.

## Run it
1. Open the folder in VS Code.
2. Open `index.html` in Chrome, or use the VS Code Live Server extension.
3. Data is saved in the browser using localStorage.

## Current modules
- Dashboard
- Smart "What should I do now?" recommendation
- Tasks
- Assignments
- Attendance
- Timetable
- AI Partner prototype
- Productivity view

## Next development stages
1. Add login and user profiles.
2. Replace localStorage with SQLite/MySQL through a Python Flask/FastAPI backend.
3. Add real calendar and notifications.
4. Add OCR for assignment/notice photos.
5. Connect an AI API for natural-language planning and tutoring.
6. Make the web app installable as a PWA / package it as Android later.

This version deliberately uses no paid API and no Flutter.
